# AIGauge 26.11.01

Mistral joins Claude and Codex in the menu bar.

- Track monthly Mistral API/Studio and Vibe Code allowances, including used,
  total, remaining, percentage, and reset time.
- Connect using the API key stored by Mistral Vibe in macOS Keychain. You can
  also verify and save a provided key in AIGauge's own Keychain entry.
- Choose Mistral's tray color, visibility and order alongside existing providers.
- Browser sessions remain an advanced alternative, with explicit macOS file
  access guidance. The default Keychain/API connection does not read cookies.
- Automated release packaging checks source privacy, bundle contents, all four
  executables, version metadata and GitHub asset checksums.

Mistral checks are read-only and never spend model tokens. Keys and cookies are
not printed or included in the release. Existing Claude and Codex credentials
and usage-refresh behavior are preserved.
